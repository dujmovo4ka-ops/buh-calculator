# Бухгалтерські послуги

Односторінковий вебдодаток для бухгалтера на аутсорсі: калькулятор вартості
пакета послуг для замовника та облік замовників — доходи, ліміти єдиного
податку, рух коштів і прибуток.

**Відкрити демо:** https://dujmovo4ka-ops.github.io/buh-calculator/

Демо заповнене вигаданими даними; кнопка «Скинути демо» повертає їх до початкового стану.

## Можливості

- **Калькулятор послуг** — списки для замовників: основні й додаткові послуги,
  кількість, період (разово / на місяць), підсумки за місяць і рік, друк у PDF.
- **Облік замовників** — помісячні доходи, контроль ліміту доходу для груп
  єдиного податку, відмітки про оплату.
- **Звіти** — рух коштів (CF) і прибуток (P&L) за рік, з урахуванням ПДВ;
  зведені звіти для групи пов'язаних замовників (ТОВ і ФОП одного власника).
- **Імпорт банківської виписки** (.xls/.xlsx).
- **Довідники** — послуги, замовники, статті доходів і витрат.
- **Архів** — знімки даних, експорт/імпорт у JSON, автозбереження у файл (Chrome/Edge).

## Дані

Усе зберігається лише у вашому браузері (localStorage) — нічого не передається на сервер.

Працює офлайн: можна просто завантажити `index.html` і відкрити у браузері.
